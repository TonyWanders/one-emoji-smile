A program that writes exactly one emoji to `/output/entry.txt`,
for the make.fun competition
[One Emoji, One Smile](https://make.fun/bounty/u-0xkianno-one-emoji-one-smile-5470751f).

Run it with Python 3:

```
python3 main.py
```

It writes the emoji below to `/output/entry.txt` (or to the path given as
the first argument, or `$OUTPUT_PATH`). No network, no clock, no
randomness. The entry is 1 character, inside the 1 to 8 gate.

## The emoji

```
🤗
```

The hugging face: a warm, open-armed welcome that reads as kind and
friendly to any stranger at first glance. It is a chosen gesture, not
the first smiley that comes to mind, and it carries no intimacy,
sarcasm or flirtation, so it works coming from someone unknown.
